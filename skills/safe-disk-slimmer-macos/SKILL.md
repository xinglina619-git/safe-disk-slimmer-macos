# Safe Disk Slimmer macOS

> 正确 skill 名称是 `safe-disk-slimmer-macos`。不要写成 `safe-dish-slimmer-macos`，否则安装和触发都可能失败。

## 当前阶段

当前版本只做 macOS 安全边界和只读分析指导，不执行真实删除。遇到用户要求清理时，必须先说明当前 skill 没有删除器，只能给出报告和人工建议。

## 不可突破的边界

1. 默认只读，不删除、移动、改名或读取文件内容。
2. 个人文件、项目文件、课程资料、聊天数据、照片、视频、备份和同步盘只报告。
3. 不修改权限、所有权、系统配置、启动项、LaunchAgents、LaunchDaemons 或应用配置。
4. 不清理 `/System`、`/Library`、`/Applications`、Time Machine、本地快照、APFS 系统卷或未知系统目录。
5. 不终止进程，不请求用户关闭安全软件，不绕过 macOS 权限。

## 分级报告

- 🟢 可考虑：未来仅限明确白名单、可重建的缓存目录；当前阶段仍只报告。
- 🟡 人工判断：开发工具缓存、包管理器缓存、Docker/Xcode 相关缓存、下载目录等。
- 🔴 禁止操作：个人资料、项目、备份、系统卷、应用安装目录、照片图库和聊天数据库。

## 效率边界

当前版本没有 macOS 扫描脚本，不适合承诺“自动扫描整机并清理”。如需提高效率，下一步应只新增只读扫描器，并先在 macOS 实机验证符号链接、挂载点和 APFS 特殊卷跳过逻辑；在这之前不得补删除器。

## 后续实现要求

如果未来加入脚本，必须新增 macOS 实机测试、符号链接/挂载点跳过、不可变计划、`plan_id` 确认和执行器二次边界验证。
